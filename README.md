# SolverStudio ⚡

> **Advanced AI-Powered Multi-Modal Problem-Solving Platform**  
> Deconstruct complex coding bugs, math/logic dilemmas, business bottlenecks, and architectural puzzles with structured AI resolution plans, code scaffolds, and interactive simulations.

---

## 🚀 Features

- **🧠 Multi-Modal Root Cause Analysis:** Deep structural diagnosis, failure vectors, and ASCII causal propagation architecture maps.
- **🛠️ Actionable Step-by-Step Plans:** Numbered, expandable implementation sequence with prerequisite checks and time estimates.
- **💻 Executable Scaffolding:** Syntax-highlighted code blocks (Highlight.js) with 1-click **Copy** and **Download** capabilities.
- **📊 Empirical Impact & Verification:** Before/after performance metrics, assertion tables, and operational safety safeguards.
- **🧪 Interactive Stress Test Simulation:** Real-time in-browser test bench simulating 1,000 asynchronous workers under stress.
- **📁 Client-Side Resolution Archive:** Private local storage drawer with search, category filtering, restore, and JSON/Markdown export.
- **🌟 Community Showcase:** Peer-reviewed trending blueprints with live interactive upvotes.
- **🔍 Omnibox & Search Integration:** OpenSearch (`opensearch.xml`) support and direct URL search parameters (`?q=your+problem`).

---

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5, CSS3 Custom Properties, JavaScript (ES6+)
- **Styling:** Custom Cyberpunk-Slate Design System + Tailwind CSS via CDN
- **Typography:** Google Fonts (*Plus Jakarta Sans* & *JetBrains Mono*)
- **Icons & Syntax:** FontAwesome 6, Highlight.js, Canvas Confetti
- **Audio Feedback:** Web Audio API synth

## 🏃 Quick Start

### Option 1: Open Directly in Browser
Simply open `index.html` in any modern web browser.

### Option 2: Run with PowerShell Server
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then visit **`http://localhost:5000/`**.

---

## 🌐 Chrome Search Engine Setup

To search directly from Google Chrome's address bar:
1. Open `chrome://settings/searchEngines`
2. Under **Site search**, click **Add**
3. Enter:
   - **Name:** `SolverStudio`
   - **Shortcut:** `@solve`
   - **URL with %s:** `http://localhost:5000/?q=%s`
